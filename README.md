# Tarea3.0 - Ejercicio:3.0.0

Esta es una aplicación básica de **Calculadora Simple** desarrollada en Python. Cuenta con pruebas automatizadas integradas, contenedorización mediante **Docker** y un flujo completo de Integración y Entrega Continua (CI/CD) usando **GitHub Actions** con publicación en **GitHub Container Registry (GHCR)**.

## 🚀 Requisitos previos

- Python 3.11 o superior (para ejecución local)
- Docker instalado (para ejecución en contenedor)
